Azure Security Engineering Labs

Hands-on Azure security engineering labs documenting the development of practical cloud security skills while preparing for the Microsoft SC-500 certification.

Overview

This repository contains hands-on security labs designed to simulate real-world Azure security engineering scenarios. Each lab focuses on implementing, testing, documenting, and validating security controls across Microsoft Azure.

Areas of Focus

* Microsoft Entra ID
* Conditional Access
* Azure RBAC
* Privileged Identity Management (PIM)
* Managed Identities
* Azure Key Vault
* Azure Policy
* Azure Storage Security
* Azure Network Security
* Azure Firewall
* Private Endpoints
* Azure SQL Security
* Microsoft Defender for Cloud
* Microsoft Sentinel
* KQL and Security Monitoring
* Vulnerability Management
* Incident Detection and Response

Lab Methodology

1. Define the security objective
2. Build the Azure environment
3. Configure the security control
4. Test the configuration
5. Identify security findings
6. Implement remediation
7. Validate the final configuration
8. Document the results with screenshots and notes

Portfolio Goals

The goal of this repository is to demonstrate practical experience with Azure security technologies through documented hands-on projects, security hardening exercises, monitoring, and simulated enterprise scenarios.

Note: These are independent hands-on labs and simulated environments created for learning and portfolio development. They do not represent professional employment experience.
